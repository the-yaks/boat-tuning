# Tuning Boat Service Surgut — сайт тюнинга лодок и катеров

Статический сайт для GitHub Pages: без сборки и серверной части.
Запись — по телефону или в MAX. Форм на сайте нет: персональные данные не собираются.

## Что настроить
1. **config.js** — телефон, ссылка на MAX, адрес, часы работы. Всё на сайте обновится само.
2. **index.html** — название, услуги, тексты. Стили (`<style>`) и скрипт (`<script>`) встроены прямо в этот файл.
3. **Фото работ** лежат в `images/works/` (`boat1-*.jpg` — полный размер, `*-thumb.jpg` — миниатюры). Список фото лодки задан в атрибуте `data-photos` блока «Наши работы» в `index.html`.

## Как опубликовать на GitHub Pages
1. Создайте на GitHub публичный репозиторий, например `boat-tuning`.
2. Загрузите в него файлы из этой папки (кнопка **Add file → Upload files** или `git push`).
3. Откройте **Settings → Pages**, в **Source** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/boat-tuning/`.

Свой домен подключается там же, в **Settings → Pages → Custom domain**.
